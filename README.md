# Minimal TODO

A minimalist TODO application built with a focus on aesthetics and productivity. Featuring a sleek flat design, smooth micro-animations, folder organization, and powerful keyboard shortcuts.

[Live Demo](https://todo.imdeepmind.com/)

## Features

- **Folder Management**: Organize tasks into dedicated folders (defaults automatically to `Inbox`) with live task stats (open & completed counts).
- **Premium Aesthetics**: Clean, distraction-free interface with a custom-curated color palette and zero-border-radius design language.
- **Dynamic Hashtags**: Type `#tag` anywhere in a task to auto-generate color-coded tag chips and interactive filter pills.
- **Dark Mode**: Seamless transition between light and dark themes with a dedicated toggle.
- **Smooth Animations**: Interactive micro-animations for adding, deleting, completing tasks, and switching views.
- **Local Persistence**: Tasks, folders, and preferences are saved automatically to your browser's local storage.
- **Responsive Design**: Works beautifully across mobile, tablet, and desktop displays.

## Productivity Shortcuts

Master your task list without touching the mouse:

|   Key    |                              Action                                |
|:--------:|--------------------------------------------------------------------|
|   `a`    | **Add Task** - Opens the task creation modal with auto-focus.      |
|   `f`    | **Folders** - Opens the folder management modal with stats.        |
|   `[`    | **Previous Folder** - Quick-switch to the preceding folder.        |
|   `]`    | **Next Folder** - Quick-switch to the following folder.            |
|   `c`    | **Clear All** - Removes all tasks in the active folder with animation. |
|  `1-9`   | **Toggle Task** - Mark the 1st through 9th task as done/undone.    |
|  `Esc`   | **Close** - Discard input and close any open modal.                |
|  `Enter` | **Confirm** - Submit task or folder inside modals.                 |

## Getting Started

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Start organizing your day!
